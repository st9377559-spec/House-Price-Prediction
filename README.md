# House Price Prediction

## Project Description
This project predicts house prices using Machine Learning.

## Dataset
Housing dataset with features like area, rooms, and other factors.

## Model
Linear Regression model was used.

## Evaluation
- MAE: 3.04  
- MSE: 20.08  
- R² Score: 0.74

## Tools Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## How to Run
1. Open notebook
2. Run all cells
